# GEO Insight · AI品牌可见性监测平台

基于真实项目制作的 Web 效果展示版本。原项目底层使用大模型，推理服务需要显卡算力支持。当前网页呈现五页交互与用户提供的华为真实测试示例；浏览器内探针生成使用领域模板与本地流式动画。


## 运行

浏览器可直接打开 dist/index.html。开发源码可运行以下命令，然后访问 http://127.0.0.1:8080。

    python3 scripts/serve.py

Python 3.10+，无第三方运行依赖。可用 --port 9000 指定端口。若本机安装 Node.js 18+，也可使用 npm start、npm run check、npm run build:single，不需要 npm install。build:single 将 dist 中 HTML 与 JavaScript 合并为离线文件。当前前端没有 API 凭据配置，.env.example 解释可选端口与密钥边界。

## 五个页面

- 监测总览包含华为默认品牌选择、平台筛选、四项 KPI、提及率、排名、情感、引用率及矩阵；其他品牌显示暂无数据。
- 品牌体检包含领域模板生成、JSON 流式动画、品牌名排除及本机历史恢复。
- 问题库包含18品牌、618篇文档汇总、华为类型分布及十条精选问题、质量评分。
- AI回答洞察对照三条用户提供的回答摘录与竞品排名。
- 智能体编排沿用参考图的七个主模块和六条连线，支持节点职责说明。
- 自动演示包含区块高亮、讲解文字、慢速滚动及停止按钮，约五分钟结束后返回总览。

## 技术架构与范围

界面使用 HTML/CSS、原生 JavaScript、SVG 图标及 CSS 图表，Hash路由切页。内存状态管理页面、筛选、生成与演示，LocalStorage保存最近十五条体检批次。静态资源可独立部署，无需GPU。

原项目参考链路为数据预处理、知识图谱抽取、Milvus持久化存储、问题生成、问题改写、批量评估、JSON输出。本仓库流程图用于职责展示，尚未执行原后端图谱抽取、向量检索、大模型推理或五平台实时测试。新增原项目PDF及9张日志截图已补充Qwen2.5-7B-Instruct、LlamaFactory/LoRA SFT、verl/GRPO实验及Milvus字段证据。截图来源说明提供原文件路径和行号。可执行原后端源码、完整配置和完整日志仍需另附。
